# Worth Demands Website

Static website for Worth Demands LLC.

## Files
- `index.html` — main site
- `styles.css` — responsive styling
- `script.js` — mobile navigation and temporary form behavior

## Before launch
Connect the contact form to Formspree (or another secure form provider) and confirm the final email routing for `info@worthdemands.com`.

The website intentionally instructs visitors not to submit confidential case records through the public contact form.
